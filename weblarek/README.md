# Web-Larek

Интернет-магазин товаров для веб-разработчиков.

## Описание

Веб-приложение, в котором пользователь может просматривать каталог товаров, добавлять их в корзину и оформлять заказ: указывать способ оплаты, адрес доставки, email и телефон. Товары загружаются с сервера, заказ отправляется на сервер.

## Стек

- TypeScript
- HTML, SCSS
- Vite

## Архитектура

Код разделён на слои по парадигме MVP:

- **Model** — слой данных: каталог товаров, корзина, данные покупателя
- **View** — слой представления: карточки товаров, корзина, формы, модальные окна
- **Presenter** — связывает данные и представление через события

Взаимодействие между слоями построено на событийно-ориентированном подходе.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
